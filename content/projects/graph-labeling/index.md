Computer Vision project built during my internship at LTIMindtree to improve the accuracy of graphical data interpretation.

## What I built

- Algorithms for precise graph labeling using edge detection and contour recognition with OpenCV.
- A FastAPI integration that improved code efficiency by 20% and achieved 90% accuracy in contour area calculations.
- Developed a custom React.js dashboard with a component-driven home page to present the processed graphs, giving the team a single entry point to every result.
- Engineered multiple dashboard tabs in React.js, each highlighting a distinct set of graphs on a reusable component layout, enabling the team to navigate from page to page more easily and smoothly.
- Designed and built a responsive, visually consistent UI across all dashboard tabs, covering layout, color scheme and reusable components, so the dashboard works cleanly on different screen sizes.
- Optimized front-end performance by implementing lazy loading for dashboard tabs and graph components, reducing initial load time and improving page responsiveness.
